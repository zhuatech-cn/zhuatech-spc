# 统计过程控制系统企业能力

## 领域覆盖

- **质量特性**：管理规格、单位、抽样和控制方法
- **抽样计划**：配置频次、样本量和分层规则
- **数据采集**：接收人工、设备和检测系统测量值
- **控制图**：支持计量与计数型控制图
- **判异规则**：执行越界、趋势、偏移和连串规则
- **过程能力**：计算Cp、Cpk、Pp、Ppk及分布
- **异常预警**：通知责任人并限制异常过程放行
- **纠正措施**：记录原因、措施、验证和关闭
- **质量分析**：按产品、设备、班组和期间分析

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对统计过程控制系统关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `QMS`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
